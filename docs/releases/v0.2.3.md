## Novidades

### Imagem .dmg no macOS

Abra o arquivo e arraste o ATUS para Aplicativos, como nos outros apps do Mac. O .zip continua disponível.

### Instalador .msi no Windows

Instala o ATUS para todos os usuários do computador e permite a implantação pelo TI em laboratórios. O instalador .exe continua sendo a opção para o seu próprio computador, sem pedir permissão de administrador.
