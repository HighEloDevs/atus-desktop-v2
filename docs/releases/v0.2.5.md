## Melhorias

- Cada pacote de instalação sai assinado. Quando as atualizações automáticas chegarem, o ATUS só vai instalar o que tiver sido publicado pela equipe.
- O histórico de novidades de todas as versões é publicado junto com cada versão, para a futura página Novidades do app.
